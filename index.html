PROJECT / 01

Deep Learning–Driven 3D Neural Structure Analysis
with PointNet++ for Alzheimer's Diagnosis

Developed a deep learning-based system to detect and classify Alzheimers disease stages using brain MRI scans. The MRI images were converted into 3D point cloud representations to capture spatial brain structure. A PointNet-based deep learning model was trained to classify four stages: NonDemented, Very Mild Dementia, Mild Dementia, and Moderate Dementia. The model was evaluated using performance metrics such as Accuracy, Precision, Sensitivity, and ROC-AUC. This project demonstrates the potential of 3D deep learning techniques for medical image analysis and early disease detection.
